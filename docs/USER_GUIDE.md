# Guide utilisateur

Choisissez vos dates dans la réservation, vérifiez le nombre de nuits et les options, puis saisissez vos coordonnées. Le montant définitif est affiché avant le paiement sécurisé Stripe. Une réservation n’est confirmée qu’après le paiement et la réception de l’email de confirmation.

Pour modifier ou annuler un séjour, utilisez les coordonnées figurant dans la confirmation et indiquez uniquement la référence de réservation. Pour un bon cadeau, conservez le numéro unique et le QR Code jusqu’à son utilisation.

En cas d’indisponibilité du site, n’effectuez pas plusieurs paiements successifs. Vérifiez d’abord votre email et votre relevé Stripe, puis contactez l’établissement. Aucune donnée de carte bancaire n’est enregistrée par Love Room Absolu.
