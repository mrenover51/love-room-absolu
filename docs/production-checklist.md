# Checklist de production

- [ ] Variables Vercel renseignées dans le bon environnement.
- [ ] Migration Supabase appliquée et RLS vérifiée.
- [ ] Compte administrateur et rôle créés.
- [ ] Domaine final, DNS et HTTPS actifs.
- [ ] Données de `lib/site-config.ts` fournies via les variables publiques.
- [ ] Mentions légales, confidentialité, annulation, dépôt et règlement validés.
- [ ] Tarifs et options remplacés par les valeurs définitives.
- [ ] Webhook Stripe test validé, puis webhook live créé.
- [ ] Domaine Resend vérifié et emails reçus.
- [ ] Imports iCal Booking/Airbnb configurés et cron contrôlé.
- [ ] Export du site importé dans Booking et Airbnb.
- [ ] Réservation concurrente refusée par la fonction atomique.
- [ ] Paiement réussi, expiré et remboursé testés.
- [ ] Parcours mobile et clavier contrôlé sur appareils réels.
- [ ] Sauvegardes Supabase et supervision Vercel activées.
